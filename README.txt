# 🌐 Cuvette Engineering (U) Ltd – Website

## 📌 Overview

This is the official website for **Cuvette Engineering (U) Ltd**, designed to present the company’s services, projects, and contact information in a modern, responsive, and professional format.

The website showcases expertise in:

* Construction & Civil Engineering
* Telecom Infrastructure
* Facility Maintenance
* Security Systems

---

## 🚀 Features

* Fully responsive design (mobile, tablet, desktop)
* Professional UI/UX layout
* Project portfolio with detailed project views
* Image optimization for fast loading
* Google Maps integration for location
* Contact section with company details
* Clean and maintainable code structure

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Responsive Design (Flexbox & Grid)

## 🖼️ Image Optimization

For best performance:

* Use **WebP format**
* Keep image sizes under **300KB**
* Use `loading="lazy"` for images

---

## 📍 Google Maps Integration

To embed location:

1. Get embed code from Google Maps
2. Paste into your HTML using an `<iframe>`
